# TeeChart with Delphi FireMonkey

A native Windows sample using the TeeChart packages included with Delphi. It displays five sample bars with a separate color for each value.

Import a Delphi Windows x86_64 SDK including `rtl`, `fmx`, `FmxTee`, and `FmxTeeUI`, and build the matching `Island.DelphiSupport` library. Open `TeeChart.elements`; the project selects the latest installed Delphi SDK.

Run on Windows with the matching Delphi runtime packages available. Debug and Release compilation has been checked; displaying the chart and interacting with the form still require a Windows GUI run.
