# Legacy samples

These examples are retained for historical reference and older platform integrations. They are not recommended starting points for new applications, and may require obsolete SDKs, frameworks or external dependencies.

Each sample keeps its original language/platform-relative path beneath `Legacy/`. The move preserves its source, resources and local project structure. Current samples remain at the repository root under their language folders.

| Original path, now under Legacy | Reason |
| --- | --- |
| [Oxygene/Echoes/Framework/Remoting](<Oxygene/Echoes/Framework/Remoting>) | Classic .NET Remoting; retained for historical interoperability. |
| [Oxygene/Echoes/Framework/WCF](<Oxygene/Echoes/Framework/WCF>) | Classic WCF service hosting and generated client. |
| [Oxygene/Echoes/Mono](<Oxygene/Echoes/Mono>) | Historical Mono-specific environment, database and desktop examples. |
| [Oxygene/Echoes/Framework/LINQ to SQL](<Oxygene/Echoes/Framework/LINQ to SQL>) | Legacy LINQ-to-SQL and externally provisioned Northwind database. |
| [Oxygene/Echoes/Language/Linq/LinqToSQL](<Oxygene/Echoes/Language/Linq/LinqToSQL>) | Legacy LINQ-to-SQL and externally provisioned database. |
| [Oxygene/Toffee/macOS/Opengl](<Oxygene/Toffee/macOS/Opengl>) | Deprecated Apple OpenGL path; use the active Metal sample for new graphics work. |
| [Oxygene/Echoes/Language/AllLanguageFeatures](<Oxygene/Echoes/Language/AllLanguageFeatures>) | Historical language declaration collection, including obsolete diagnostic notes. |
| [Oxygene/Cooper/Android/Torch](<Oxygene/Cooper/Android/Torch>) | Historical screen torch, menu and dialog APIs. |
| [Oxygene/Cooper/Android/JetBoy](<Oxygene/Cooper/Android/JetBoy>) | Historical Android game; Snake remains in the active collection. |
| [Oxygene/Cooper/Android/LunarLander](<Oxygene/Cooper/Android/LunarLander>) | Historical Android game; Snake remains in the active collection. |
| [Oxygene/Echoes/Windows Forms/Horse Race](<Oxygene/Echoes/Windows Forms/Horse Race>) | Historical desktop animation example; Memory remains in the active collection. |

Go By Example and Tour of Go remain active Go-specific tutorial collections. Go By Example is retained for a later build/runtime test pass; it is not a language-porting backlog.
